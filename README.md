# data branch

Generated by the workflows in `main`. This branch is **squash-force-pushed**: it always holds
exactly one commit, so it never grows. Do not commit here by hand.

- `observations/year=YYYY/month=MM/part-0.parquet`: granule-tracking table (one row per granule x source)
- `state/cursors.json`: listing/stream cursors
- `health.json`: per-source poller health
- `schedule/upcoming_passes.parquet` (+ `.meta.json`): upcoming-pass schedule, plus the footprint grids
- `tle.json`: orbital elements for the map's live satellites
